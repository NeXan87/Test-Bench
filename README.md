# Тестовый стенд для двигателей и клапанов на Arduino Nano

![Arduino Nano](https://img.shields.io/badge/Platform-Arduino_Nano-blue)
![License](https://img.shields.io/badge/License-MIT-green)

Универсальный тестовый стенд для проверки реле, двигателей, воздушных клапанов и другого промышленного оборудования с поддержкой ручного и автоматического режимов работы.

💾 Скачать [Руководство по эксплуатации](https://github.com/NeXan87/Test-Bench/blob/main/Manual.docx?raw=true)!

📷 Открыть [галерею с фото](https://github.com/NeXan87/Test-Bench/tree/main/Gallery)

## 🔧 Основные возможности

- **4 канала управления реле** (2 группы по 2 реле 24В и 2 пускателей 380В)
- **5 режимов работы**:
  - Ручной с взаимной блокировкой (переключатель реле)
  - Ручной независимый (реле управляются одновременно)
  - Испытание двигателя с тормозом (одновременное включение реле 24В и пускателя 380В)
  - Автоматический синхронный цикл
  - Автоматический асинхронный цикл
- **Гибкая настройка времён**:
  - Время включения реле: 1–60 сек
  - Задержка между циклами: 0–60 сек (с ограничениями по группам)
  - Количество циклов: 1–1000 или бесконечно
- **Защита и безопасность**:
  - Блокировка недопустимых комбинаций
  - Защита от одновременного включения в ручных режимах
  - Автоматическая остановка по завершению циклов
- **Расширенная индикация**:
  - 4 светодиода состояния
  - LCD 2004 дисплей с I2C интерфейсом
  - Отображение постоянного тока нагрузки
- **Удобное управление**:
  - 3 кнопки: Пуск 1, Пуск 2, Стоп
  - 2 переключателя для выбора режима и группы
- **Режимы калибровки и диагностики**:
  - Предназначены для тонкой настройки стенда

## ⚙️ Режимы работы

### Выбор режима (переключатель D0/D1)

| D0   | D1   | Режим                         |
| ---- | ---- | ----------------------------- |
| LOW  | LOW  | Ручной с взаимной блокировкой |
| HIGH | HIGH | Ручной независимый            |
| HIGH | LOW  | Автоматический синхронный     |
| LOW  | HIGH | Автоматический асинхронный    |

### Выбор группы (переключатель D6)

- **LOW**: Группа A (реле 1=D4, реле 2=D5)
- **HIGH**: Группа B (пускатель 1=D2, пускатель 2=D3)

### Особенности режимов

- **Режим 1**: Взаимная блокировка реле (как реверсивный пускатель)
- **Режим 2**: Независимое управление реле, возможна одновременная работа
- **Режим 2, группа B**: Одновременное включение реле 24В и пускателя 380В для испытания эл. двигателя с тормозом
- **Режим 3**: Синхронный цикл: реле1 → задержка → реле2 → задержка → повтор
- **Режим 4**: Асинхронные циклы: каждое реле работает независимо по своим таймерам

### Ограничения

- Режим 4 **заблокирован для группы B** (мигание всех светодиодов)
- Для группы B минимальная задержка = 1 секунда
- Ограничение по превышению тока с выключением реле

## 🖥️ Индикация на дисплее

```
R1→10s  D1→05s  M→3
R2→08s  D2→03s  G→A
C→0000/INF    I→0.0A
T→00:00:00      WORK
```

- **R1/R2**: Время включения реле 1/2 или пускателей 1/2
- **D1/D2**: Задержка после реле 1/2 или пускателей 1/2
- **M**: Номер режима (1-4)
- **G**: Выбранная группа (A - реле 24V / B - реверсивные пускатели 380V)
- **C**: Текущий/всего циклов (∞ = бесконечно)
- **I**: Постоянный ток нагрузки в амперах
- **T**: Текущее время цикла
- **Статусы**: STOP / OVERLOAD / FINISH / LOCKED / PAUSED / WT BRAKE / WT MOTOR / ER BRAKE / WORK / READY

## 🛡️ Рекомендации по помехоустойчивости (промышленная эксплуатация)

Если ваше устройство работает рядом с **пускателями, двигателями 380 В или индуктивными нагрузками**, следуйте этим правилам. Иначе — **будете ловить глюки, зависания и сбои**.

### 🔌 1. Разделяйте силовые и сигнальные цепи
- **Никогда не прокладывайте 380 В и 24 В/5 В в одной косе**.
- Минимальное расстояние: **20 см** или **перпендикулярное пересечение**.
- Используйте **отдельные кабели**: силовой — в одной гофре, управляющий — в другой (экранированный).

### 🛡️ 2. Экранируйте — но правильно
- Экран управляющего кабеля **заземляйте ТОЛЬКО в одной точке**.
- Если **GND Arduino изолирован** — **не соединяйте экран с PE**!
  - Вместо этого: **экран → GND Arduino** или **экран → никуда**.
- Используйте **витую пару** для всех сигнальных линий.

### ⚡ 3. Гасите выбросы на источнике
- **На катушках пускателей** ставьте **RC-снабберы** (0.47 мкФ X2 + 220 Ом, 2 Вт).
- **На силовых контактах** — **дополнительные снабберы**, если есть дуга.
- **Диоды Шоттки (1N5819) или 1N4007** — параллельно катушке (катод к +24 В).

### 🔋 4. Питание — ваша первая линия обороны
- Питание Arduino — **только от изолированного источника** (трансформатор + стабилизатор).
- На входе 5 В — **LC-фильтр**: 10 мкГн + 470 мкФ + 100 нФ.
- **Не соединяйте GND Arduino с PE напрямую**.
  - Вместо этого: **GND ↔ PE через Y1-конденсатор 2.2 нФ (250/500 В AC)**.

### 📡 5. Защищайте все внешние пины
- **На каждый сигнал, выходящий из экрана**:
  - **TVS-диод**: **SMBJ5.0CA** (двунаправленный!).
  - **Конденсатор**: 100 пФ (данные) или 100 нФ (питание).
  - **Резистор**: 220–470 Ом последовательно (I²C).
- **Особое внимание**: I²C, ADC (A7), кнопки (D0–D9).

### 🧪 6. Тестируйте в реальных условиях
- **Глюки без нагрузки** — нормальны (резонанс в петле кабеля).
- **Главное — стабильность при подключённом двигателе**.
- Если работает с нагрузкой — **всё в порядке**.

> 💡 **Помехи неизбежны. Но их можно контролировать.**  
> Эти меры проверены в реальной эксплуатации с двигателями, пускателями и 380 В сетью.

## 🚀 Установка

1. Склонируйте репозиторий:
   `git clone https://github.com/NeXan87/Test-Bench`

2. Установите необходимые библиотеки через Arduino IDE:

- Скетч → Подключить библиотеку → Управление библиотеками
- Найдите и установите Bounce2, ACS712 и LiquidCrystal I2C

3. Отключите внешнее питание и переведите стенд в 1-й режим
4. Откройте папку проекта в Arduino IDE и загрузите скетч
5. Настройте параметры в файле config.h под ваше оборудование
